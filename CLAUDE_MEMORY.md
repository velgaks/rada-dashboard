# Claude Memory — Verkhovna Rada Voting Dashboard

## Project Overview
A single-file (`index.html`) **Modern Newsroom**-styled dashboard for the Ukrainian parliament (Верховна Рада) 9th convocation voting data. Playfair Display serif headlines, yellow-blue flag stripe, editorial transparent layout. Fetches open-data CSV + JSON from `data.rada.gov.ua`, joins on `id_question`, and renders metrics, charts, and a filterable vote table. No browser caching — data fetched fresh on each load.

## Data Sources
| Endpoint | Size | Format | Key Columns |
|----------|------|--------|-------------|
| `https://data.rada.gov.ua/ogd/zal/ppz/skl9/plenary_result_event-skl9.csv` | ~1 MB | CSV | `date_agenda, id_question, id_event, for, against, abstain, not_voting, total, presence, absent, voting_result` |
| `https://data.rada.gov.ua/ogd/zal/ppz/skl9/plenary_agenda-skl9.json` | ~10 MB | JSON | `date_agenda, id_question, name_question` |
| `https://data.rada.gov.ua/ogd/zal/ppz/skl9/dict/factions.json` | tiny | JSON | Faction names by ID (loaded at runtime to avoid hardcoding) |
| `faction_summary.json` | 268 KB | JSON | `{ "YYYY-MM-DD": { "faction_id": { for, against, abstain, not_voting, absent } } }` |

- CORS open on all endpoints — no proxy needed.
- `voting_result`: `1` = passed, `0` = failed.
- Join key: `id_question` (cast with `Number()`).
- TSV results column format: `deputy_id:faction_id:vote_code|...` (vote codes: 1=За, 2=Проти, 3=Утримався, 4=Не голосував, 0=Відсутній)
- Faction names from API have verbose prefixes — cleaned with regex: strip "Фракція політичної партії", "Депутатська група", " у Верховній Раді України", and all `"` chars.

## Layout / Features (current state)

### Tabs
- **Огляд** — metric cards + charts
- **Голосування** — vote table

### Header filter
- 4 preset buttons: Останнє | Місяць | 3 місяці | Весь час
- Two `<input type="date">` fields (from / to) with `color-scheme: dark`
- URL persistence via `?from=&to=` query params

### Metric Cards (4)
- Присутніх (max across filtered sessions)
- Прийнято / Провалено counts
- Середній % «за»

### Charts (Огляд tab) — each has an ⓘ info popup tooltip
- Attendance bar chart (last 15 sessions or full range, green/red + quorum line)
- Average "За" votes bar chart (per session, quorum line)
- C1: Faction % «за» trend lines (top 5 factions by volume, 3-session rolling average)
- C2: Pass rate bar chart (% bills passed per session, green ≥70% / yellow 40-70% / red <40%)
- C3: Coalition dependency stacked area chart (monthly aggregation, quorum line at 226)
- C4: Faction attendance heatmap (factions × sessions grid, color-coded by presence rate)

### Votes Table (Голосування tab)
- Virtual scroll: renders 50 rows at a time via IntersectionObserver sentinel
- Search input filters by bill name (re-runs renderRows on filtered subset)
- **«Завантажити CSV»** button — exports exactly what's on screen (date range + initiator
  filter + search + sort), RFC 4180 quoted, UTF-8 BOM for Excel
- Search and sort compose through one `applyTableView()` pipeline. `renderRows()` is the single
  funnel that records `currentVisibleRows`, which is what the CSV export reads.
- Date column added
- Columns: # | Дата | Назва питання | За | Проти | Утрим | Не голос | Явка | Результат
- Row click → new tab: `https://w1.c1.rada.gov.ua/pls/radan_gs09/ns_golos?g_id={id_event}`

## Known Issues / Gotchas
- **`faction_summary.json` is not 1:1 with the CSV** — the CSV has 439 distinct session dates,
  the faction summary 438. `2025-09-02` exists upstream but is absent from the summary. Historical
  and low impact, but don't re-diagnose it as a broken pipeline. (Checked 2026-08-05.)
- **Recess looks identical to breakage.** Before concluding the data is stale, check the
  *upstream* `Last-Modified` on `plenary_result_event-skl9.csv`. The Rada breaks for summer
  (roughly mid-July to early September) and winter; during recess the dashboard correctly shows
  the last sitting date and CI correctly commits nothing.
- **GitHub Pages `Last-Modified` is the deploy time, not the file's change time.** A daily CI
  commit re-stamps every file on the site, so Pages headers can't tell you when `index.html`
  actually changed — use `git log` or the GitHub commits API for that.
- Node **is** installed at `C:\Program Files\nodejs\node.exe` — useful for `node --check` on the
  extracted inline script. (An older note in CLAUDE_ERRORS.md claimed no Node; that's obsolete.)
- `presence` field can exceed 393 in source data (data quality issue in rada.gov.ua) — display raw number without denominator
- sessionStorage caching was removed (quota issues) — data fetched fresh each load
- `python` command not found on this machine — use `py`
- TSV is 68 MB — never fetch in browser, always pre-process with Python
- Faction name from API has nested quotes (e.g., `"Партія "За майбутнє"`) — use `.replace(/"/g, '')` after prefix/suffix removal
